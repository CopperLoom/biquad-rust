Setup Instructions — biquad-fit Rust
=====================================

1. INITIALIZE GIT REPO
   cd ~/claude/biquad-rust
   git init
   git add docs/ARCHITECTURE.md PLAN.md setup.txt
   git commit -m "docs: architecture spec and implementation plan"

2. INITIALIZE RUST PROJECT
   cargo init --lib
   # This creates Cargo.toml and src/lib.rs

   Add to Cargo.toml [dependencies]:
     slsqp = "1"
     serde = { version = "1", features = ["derive"] }
     serde_json = "1"

   Add to Cargo.toml [dev-dependencies]:
     approx = "0.5"
     criterion = { version = "0.5", features = ["html_reports"] }

   Add to Cargo.toml:
     [[bench]]
     name = "optimize_benchmark"
     harness = false

3. COPY TEST FIXTURES FROM TYPESCRIPT PROJECT
   Source: ~/claude/biquad-fit/tests/fixtures/
   Dest:   ~/claude/biquad-rust/tests/fixtures/

   mkdir -p tests/fixtures
   cp -r ../biquad-fit/tests/fixtures/fr      tests/fixtures/
   cp -r ../biquad-fit/tests/fixtures/targets  tests/fixtures/
   cp -r ../biquad-fit/tests/fixtures/golden   tests/fixtures/

   These are JSON files:
   - fr/         5 IEM measurements (blessing3, hexa, andromeda, zero2, origin_s)
   - targets/    6 target curves (harman_ie_2019, diffuse_field, flat, v_shaped, bass_heavy, bright)
   - golden/     90 AutoEQ reference outputs (golden-file format with rmse, filters, pregain)

4. COPY GOLDEN FILE GENERATOR (optional, for regenerating)
   cp ../biquad-fit/tests/generate_golden.py tests/
   # Requires Python venv with autoeq installed — see biquad-fit/.venv/

5. CREATE .gitignore
   /target
   Cargo.lock

6. CREATE DIRECTORY STRUCTURE
   mkdir -p src tests/helpers benches

7. REFERENCE IMPLEMENTATIONS (local paths for reading)
   These paths are referenced in docs/ARCHITECTURE.md — verify they exist:

   AutoEQ Python source (the correctness oracle):
     ../biquad-fit/.venv/lib/python3.9/site-packages/autoeq/
     Key files: peq.py, frequency_response.py, utils.py, constants.py

   TypeScript biquad-fit source (prior port):
     ../biquad-fit/src/
     Key files: optimize.ts, equalize.ts, smooth.ts, biquadResponse.ts,
                interpolate.ts, compensate.ts, applyFilters.ts, types.ts

   TypeScript detailed spec:
     ../biquad-fit/docs/joint-optimizer-spec.md

   If your Python venv path differs (e.g. python3.11 instead of 3.9),
   update the path in docs/ARCHITECTURE.md "Local Path" column.

8. VERIFY
   cargo check          # should compile (empty lib)
   ls tests/fixtures/golden/ | wc -l   # should show 90 files
